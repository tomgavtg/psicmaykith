# Repositorio documental de avisos de privacidad

## Estado

El aviso integral del sitio, contacto inicial, agenda y pago `v1.1` fue aprobado por la
responsable y entró en vigor el 6 de agosto de 2026. La versión `v1.0` se conserva como

mantiene dentro del repositorio Git de la plataforma para evitar un repositorio Git
anidado y conservar revisión, historial y trazabilidad junto con el código que recaba
los datos.

Fecha de elaboración inicial: 1 de agosto de 2026.

## Gobierno de versiones

1. No editar una versión ya publicada. Crear `v0.2`, `v1.1`, etcétera.
2. `v0.x` significa borrador; `v1.0` sólo puede asignarse después de revisión jurídica,
   aprobación de la responsable y validación contra la operación real.
3. Registrar fecha de entrada en vigor y conservar una copia de cada versión puesta a
   disposición.
4. El texto publicado en Sanity debe coincidir literalmente con el archivo aprobado.
5. Cambios de finalidad, proveedor, datos, transferencia, retención, atención de
   menores o canal ARCO requieren nueva evaluación.

## Límites

Estos documentos no son asesoría jurídica ni acreditan por sí solos cumplimiento. La
Ley exige que el aviso describa el tratamiento real. Antes de publicar deben cerrarse
los valores `[POR DEFINIR: ...]`, contratos y configuración de proveedores.

Sanity administra contenido público; no debe usarse para expedientes, mensajes de
pacientes, consentimientos firmados ni solicitudes de cita.
